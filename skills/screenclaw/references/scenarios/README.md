# ScreenClaw 场景模板

此目录用于沉淀已验证的操作流程，按应用划分文件夹。

## 目录结构

```
scenarios/
├── README.md                    # 本文件
├── .gitkeep                     # 保持目录结构
├── notepad/                     # 记事本应用场景
│   └── (添加场景模板文件)
├── wechat/                      # 微信应用场景
│   └── (添加场景模板文件)
└── {应用名}/                    # 其他应用场景
    └── (添加场景模板文件)
```

## 场景模板格式

**场景模板的完整格式请参考主技能文档 SKILL.md 中的"场景模板机制"部分。**

此处仅列出简要结构：

```markdown
---
name: {app-name}-{scenario-name}
description: {什么时候应该用这个场景模板}
---

# {应用名} - {场景名}

## 适用场景
{详细描述这个场景适用的条件，帮助AI判断何时使用}

## 目标软件
- 进程名：xxx.exe
- 窗口标题关键词：xxx
- 窗口尺寸比例：宽高比
- 主窗口子窗口关系：是否需要使用子窗口id

## 公共配置
- 推荐网格参数：density=X, opacity=Y, color=Z
- 推荐数字参数：number_density=X, number_size=Y
- 推荐操作方式：background/hijack

## 操作步骤
| 步骤 | 操作 | 坐标 | 操作模式 | 参数 | 等待 | 说明 |
|------|------|------|----------|------|------|------|
| 1 | click | (50, 35) | background | - | 200ms | 点击xxx按钮 |

## batch格式
```json
{
  "instructions": [
    { "action": "click", "params": { "x": 50, "y": 35, "action_method": "background" } },
    { "action": "wait", "params": { "duration_ms": 200 } }
  ]
}
```

## 添加新场景

当任务成功完成后，如果用户同意沉淀操作流程：

1. 在对应的 `{应用名}/` 文件夹下创建新的 `.md` 文件
2. 文件命名：`{场景名}.md`
3. 按照上述格式填写内容
4. 在主技能文档中添加索引

## 应用级配置

如果某个应用有特殊的推荐配置，可以在应用文件夹下创建 `config.md`：

```markdown
# {应用名} 配置

## 推荐网格参数
- density: 10.0（此应用元素较密集）
- opacity: 30（此应用背景较深）

## 推荐操作方式
- 优先使用 hijack（此应用不支持 background）

## 其他注意事项
- 此应用的窗口需要特殊处理
```
