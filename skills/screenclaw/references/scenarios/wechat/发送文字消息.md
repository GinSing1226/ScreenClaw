# 微信 - 发送文字消息

## 目标说明

- 进程名：Weixin.exe
- 窗口标题关键词：微信
- 窗口清单：
| 窗口名 | 类型 | 获取方式 | 尺寸比例 | 可用操作 | 说明 |
|--------|------|----------|----------|----------|------|
| 主窗口 | 主窗口 | get_window_list ，标题"微信"，或进程名weixin.exe | 1920:1039 | 所有操作 | 应用的主界面 |
| 搜索窗口 | 动态窗口 | 搜索时临时生成，window_id一般为7位数 | 无需关注，实时判断位置 | click | 搜索结果弹出窗口，需动态获取ID后操作 |


- **搜索窗口说明**：微信搜索时会在主进程下动态创建一个新的独立窗口（标题"Weixin"，无子窗口），该窗口每次搜索时新建，ID不固定。搜索关闭后窗口消失。需通过 get_window_list 获取，筛选7位数window_id且标题为"Weixin"的独立窗口。
- **窗口尺寸比例说明**：如果截图的大小尺寸 与 窗口尺寸比例不同，不推荐复用坐标。

## 场景业务流概述

**场景描述**（5W2H）：
- Who：用户想要给某个联系人或群聊发消息
- What：通过搜索找到目标，输入文字并发送
- Where：微信主窗口 + 搜索弹窗
- When：用户需要发消息时触发
- Why：实现自动化发送微信消息
- How：切换通讯录 → 清除搜索 → 输入搜索词 → 获取搜索窗口 → 截图定位 → 点击搜索结果 → 输入消息 → 点击发送
- How Much：约30秒，8个步骤

**用户需要提供**：
1. 发给谁（联系人名称或群聊名称）
2. 发送什么内容（文字消息）

**环境假设**：
- 微信已登录并显示在桌面上（未最小化）
- 使用 background 操作模式

**全景业务流**：
```
节点1(切换通讯录) → 节点2(清除搜索) → 节点3(输入搜索词) → 节点4(获取搜索窗口+截图定位) → 节点5(点击搜索结果) → 节点6(输入消息+发送)
```

## 业务流节点详解

### 节点1：切换到通讯录

**T（触发）**：开始执行发消息任务

**I（输入）**：无额外输入

**P（处理）**：点击通讯录图标，进入通讯录页面。原因：通讯录的搜索结果能固定住，之前输入的文案也还在，比较稳定。

> **固定坐标**：
> | 操作 | 坐标 | 使用窗口 | 操作模式 | 等待 | 说明 |
> |------|------|----------|----------|------|------|
> | click | 2x16 | 主窗口 | background | 500ms | 点击通讯录图标 |

**O（输出）**：无

**E（异常）**：如果通讯录图标位置变化，需重新截图定位

---

### 节点2：清除搜索框

**T（触发）**：通讯录页面已打开

**I（输入）**：无

**P（处理）**：点击搜索框右侧的清除按钮，清除上一次搜索内容。

> **固定坐标**：
> | 操作 | 坐标 | 使用窗口 | 操作模式 | 等待 | 说明 |
> |------|------|----------|----------|------|------|
> | click | 14.5x6 | 主窗口 | background | 500ms | 点击清除搜索按钮 |

**O（输出）**：无

**E（异常）**：如果无历史搜索，清除按钮可能不存在，不影响后续步骤

---

### 节点3：输入搜索词

**T（触发）**：搜索框已清空

**I（输入）**：用户提供的联系人/群聊名称

**P（处理）**：在搜索输入框输入搜索关键词。

> **固定坐标**：
> | 操作 | 坐标 | 使用窗口 | 操作模式 | 等待 | 说明 |
> |------|------|----------|----------|------|------|
> | input_text | 9x6 | 主窗口 | background | - | 输入搜索词 |

**O（输出）**：无

**E（异常）**：如果 input_text 无效，检查是否需要使用主窗口而非子窗口操作

---

### 节点4：获取搜索窗口并截图定位

**T（触发）**：搜索词已输入

**I（输入）**：无

**P（处理）**：
1. 调用 get_window_list（keyword=Weixin, include_children=true, children_filter=all）获取窗口列表
2. 从结果中筛选：属于主进程（PID 14868）、标题为"Weixin"、无子窗口、window_id为7位数的独立窗口，即为搜索窗口
3. 对搜索窗口截图（使用默认网格参数）
4. 分析截图，定位目标联系人/群聊的位置

> **动态坐标**：
> - 关注区域：搜索结果列表
> - 识别特征：目标名称通常在第一位或中间位置
> - 定位要点：根据文字内容匹配目标

**O（输出）**：搜索窗口ID + 目标坐标

**E（异常）**：
- 如果搜索窗口未出现：检查步骤3是否成功输入文本
- 如果搜索结果中没有目标：搜索词可能有误，向用户确认

---

### 节点5：点击搜索结果

**T（触发）**：已定位到目标在搜索结果中的坐标

**I（输入）**：从节点4获取的搜索窗口ID和目标坐标

**P（处理）**：在搜索窗口上点击目标联系人/群聊。

> **动态坐标**：
> | 操作 | 坐标 | 使用窗口 | 操作模式 | 说明 |
> |------|------|----------|----------|------|
> | click | {从截图读取} | 搜索窗口 | background | 点击目标搜索结果 |

**O（输出）**：无

**E（异常）**：如果点击后未进入对话界面，可能坐标偏移，重新截图定位

---

### 节点6：输入消息并发送

**T（触发）**：已进入目标对话界面

**I（输入）**：用户提供的消息内容

**P（处理）**：在输入框输入消息文本，然后点击发送按钮。

> **固定坐标**：
> | 操作 | 坐标 | 使用窗口 | 操作模式 | 等待 | 说明 |
> |------|------|----------|----------|------|------|
> | input_text | 30x90 | 主窗口 | background | 300ms | 输入消息内容 |
> | click | 97x96 | 主窗口 | background | - | 点击发送按钮 |

**O（输出）**：无

**E（异常）**：如果发送失败，检查输入框是否获得焦点

---

## 节点指令
### 规则
1. 节点1+2+3 使用固定坐标，可组合成一条 batch 指令。节点4需动态获取。节点5依赖节点4结果。节点6使用固定坐标。
2. 尽可能使用batch端点。powershell请使用`api_call_batch.ps1`执行batch端点。
3. 微信不支持background模式输入换行符、emoji。若包含，请切换hijack模式。具体阅读`references/api/input_text.md`

### 代码实力
```bash
# 节点1+2+3 组合（全部固定坐标，batch执行）
# python示例如下
# 需要填充：{搜索词}
python -c "
import requests, json
url = '{api_url}/api/batch'
headers = {
    'Authorization': 'Bearer {token}',
    'Content-Type': 'application/json'
}
body = {
    'ai_app_type': '{ai_app_type}',
    'session_id': '{session_id}',
    'window_id': {main_window_id},
    'main_window_id': {main_window_id},
    'action_method': 'background',
    'instructions': [
        {'action': 'click', 'params': {'x': 16, 'y': 16}},
        {'action': 'wait', 'params': {'duration_ms': 500}},
        {'action': 'click', 'params': {'x': 14.5, 'y': 6}},
        {'action': 'wait', 'params': {'duration_ms': 500}},
        {'action': 'input_text', 'params': {'x': 9, 'y': 6, 'text': '{搜索词}'}}
    ]
}
r = requests.post(url, headers=headers, json=body, timeout=60)
print(json.dumps(r.json(), ensure_ascii=False, indent=2))
"

# 节点4：获取搜索窗口
# 调用 get_window_list，筛选7位数window_id的独立窗口
# 对该窗口截图，定位目标位置。截图参数默认即可。

# 节点5：点击搜索结果（依赖节点4的动态坐标）
# 需要填充：{搜索窗口ID}、{目标坐标}
python scripts/api_call.py {api_url} {token} click \
  ai_app_type={ai_app_type} session_id={session_id} \
  main_window_id={main_window_id} window_id={搜索窗口ID} \
  x={目标x} y={目标y}

# 节点6：输入消息并发送（固定坐标，可batch）
# 需要填充：{消息内容}
python -c "
import requests, json
url = '{api_url}/api/batch'
headers = {
    'Authorization': 'Bearer {token}',
    'Content-Type': 'application/json'
}
body = {
    'ai_app_type': '{ai_app_type}',
    'session_id': '{session_id}',
    'window_id': {main_window_id},
    'main_window_id': {main_window_id},
    'action_method': 'background',
    'instructions': [
        {'action': 'wait', 'params': {'duration_ms': 500}},
        {'action': 'input_text', 'params': {'x': 30, 'y': 90, 'text': '{消息内容}'}},
        {'action': 'wait', 'params': {'duration_ms': 300}},
        {'action': 'click', 'params': {'x': 97, 'y': 96}}
    ]
}
r = requests.post(url, headers=headers, json=body, timeout=60)
print(json.dumps(r.json(), ensure_ascii=False, indent=2))
"
```

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| input_text无效果 | 使用了子窗口ID | 微信只能用主窗口操作，确保window_id使用主窗口ID |
| 搜索窗口未出现 | 搜索词输入失败 | 检查步骤3是否成功，确认用的是主窗口 |
| 点击搜索结果无效 | 坐标偏移到其他结果 | 截图确认坐标，注意是否正确获取搜索进程 |
| 点击联系人/群无效 | 坐标偏移、进程错误、进程被关闭 | 检查截图是否为搜索进程的截图。截图判断搜索结果位置过程中，用户不能操作微信，否则搜索进程会被关闭。正确判断用户期望的联系人的位置 |
| 输入内容没有正确换行、没有包含emoji | 操作模式不对 | 如果输入内容包含换行符、emoji，需切换hijack模式 |
