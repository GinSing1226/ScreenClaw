# 微信 wiki

## 应用信息

- 英文名：WeChat
- 中文名：微信
- 进程名：Weixin.exe（有多个进程，主进程占用内存最大）
- 窗口标题关键词：微信、Weixin

## 术语表

| 术语 | 含义 |
|------|------|
| 聊天列表 | 左侧的会话列表区域，展示用户与通讯录的人或群聊卡片 |
| 搜索 | 左侧的会话列表的顶部，有“搜索”文案的区域，可以搜索微信的任何内容 |
| 输入框 | 主窗口右侧下方的消息输入区域 |
| 工具栏 | 输入框下方的表情、文件等图标栏 |
| 发送按钮 | 输入框右下角的发送按钮，用于发送信息 |
| 消息气泡 | 聊天记录中的消息，自己的消息在右侧，其他人的消息在左侧 |

## 窗口操作规则

- **只能用主窗口操作**：微信的所有操作（click、input_text等）都必须使用主窗口ID，子窗口（Chrome_WidgetWin_0、Chrome Legacy Window等）无法响应操作
- **搜索窗口是动态的**：搜索时会创建一个新的独立窗口（标题"Weixin"，无子窗口，window_id一般为7位数），该窗口每次搜索新建，搜索关闭后消失。操作搜索结果需要使用这个动态窗口ID
- **搜索是实时的**：微信搜索不需要回车，输入文字后实时展示结果。
- **通讯录搜索更稳定**：通过通讯录页面的搜索界面，比首页搜索更稳定
- **点击14.5x6即清除**：点击搜索框右侧清除按钮(14.5x6)即可清除上一次搜索内容，不需要Ctrl+A等操作
