# scroll_screenshot - 滚动长截图

## 使用前必读

### 使用目的和效果
对指定窗口执行自动滚动、连续截图、智能拼接，生成完整的长图。适用于需要截取超出单屏显示的长内容（如长网页、长文档、聊天记录等）。

**核心特性**：
- 自适应滚动幅度：前3张截图自动检测最佳滚动参数
- 智能重叠检测：四重验证机制防止误匹配
- 固定区域裁剪：自动识别并去除固定头部/尾部
- 自动停止：内容不再变化时自动停止
- 固定hijack：滚动截图需要窗口到前台，固定hijack操作模式

### 适用场景
- 长页面截图（文章、论坛帖子、博客）
- 长文档截图（PDF、Word、网页版文档）
- 聊天记录截图（微信、QQ等）
- 数据列表截图（表格、列表等长数据）
- 日志文件截图（代码、日志、配置文件）

### 不适用场景
- ❌ 需要定位元素的截图（本功能不支持网格坐标绘制）
- ❌ 动态加载内容（内容无限滚动，无法自动停止）
- ❌ 非垂直滚动（横向滚动、斜向滚动）
- ❌ 分页内容（需要点击翻页而非滚动）

## 请求

**方法**：POST `/api/scroll_screenshot`

**请求头**：
```
Authorization: Bearer {token}
Content-Type: application/json
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `ai_app_type` | string | 是 | - | AI应用类型 |
| `session_id` | string | 是 | - | 会话唯一标识 |
| `window_id` | int | 是 | - | 目标窗口句柄，可以是主窗口、子窗口id |
| `main_window_id` | int | 是 | - | 主窗口ID（用于激活最小化窗口） |
| `x` | float | 否 | 50.0 | 滚动起始X坐标(0.0-100.0，百分比) |
| `y` | float | 否 | 50.0 | 滚动起始Y坐标(0.0-100.0，百分比) |
| `max_scrolls` | int | 否 | 20 | 最大滚动次数 |
| `scroll_percent` | float | 否 | 0.85 | 初始滚动幅度(0.1-0.95) |
| `scroll_wait` | float | 否 | 1.0 | 滚动等待时间(秒) |
| `target_overlap_min` | float | 否 | 0.35 | 目标重叠下限(0.10-0.50) |
| `target_overlap_max` | float | 否 | 0.45 | 目标重叠上限(0.20-0.60) |
| `stop_threshold` | float | 否 | 0.0001 | 停止阈值(0.0-0.01) |

## 参数说明

### 基础参数

#### `x` / `y`
滚动起始点坐标（百分比），用于指定滚动操作的焦点位置。

- **默认值**：50.0, 50.0（窗口中心）
- **取值范围**：0.0-100.0
- **调整建议**：
  - 窗口有分栏布局 → 设置x指向目标分栏（如左侧分栏设x=25）
  - 窗口有固定侧边栏 → 设置y避开侧边栏区域
  - 多列内容 → 设置x指向目标列
  - 一般情况 → 使用默认值50.0即可

#### `max_scrolls`
最大滚动次数，防止无限滚动。

- **默认值**：20
- **取值范围**：1-100
- **调整建议**：
  - 长文档：50-100
  - 普通网页：20-30
  - 聊天记录：10-20

#### `scroll_percent`
每次滚动占窗口高度的比例。

- **默认值**：0.85
- **取值范围**：0.1-0.95
- **调整建议**：
  - 滚动太快导致漏内容 → 减小（如0.70）
  - 滚动太慢效率低 → 增大（如0.90）

**注意**：系统会自动调整此参数以获得最佳重叠，初始值仅作参考。

#### `scroll_wait`
每次滚动后等待的时间（秒），用于页面加载。

- **默认值**：1.0
- **取值范围**：0.1-10.0
- **调整建议**：
  - 动态内容多 → 增大（如1.5-2.0）
  - 静态内容 → 减小（如0.5）

### 高级参数

#### `target_overlap_min` / `target_overlap_max`
目标重叠比例区间，用于自适应调整。

- **默认值**：min=0.30, max=0.45
- **含义**：
  - 重叠 < 30%：可能漏内容，减小滚动幅度
  - 30% ≤ 重叠 ≤ 45%：理想状态，保持
  - 重叠 > 45%：效率低，增大滚动幅度

#### `stop_threshold`
停止阈值，内容变化率低于此值时停止。

- **默认值**：0.0001（0.01%）
- **取值范围**：0.0-0.01
- **调整建议**：
  - 到底部还继续滚 → 减小（如0.00005）
  - 没到底就停止 → 增大（如0.0002）

## 错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| `WINDOW_NOT_FOUND` | 窗口不存在 | 重新获取窗口列表 |
| `PROCESS_BLOCKED` | 进程在禁止清单中 | 检查ScreenClaw的禁止列表配置 |
| `UNSUPPORTED_MODE` | 不支持的操作模式 | 只支持 hijack 或 delegated 模式 |
| `SCREENSHOT_FAILED` | 截图失败 | 窗口可能已最小化或被遮挡 |
| `OPERATION_FAILED` | 操作失败 | 滚动操作执行失败 |
| `USER_DENIED` | 用户拒绝操作 | 用户在劫持确认时拒绝 |

## 使用限制

### 模式限制
本功能**操作模式** 固定为 `hijack` ，**不支持** `background` 模式。

**原因**：向上滚动（回滚）需要劫持鼠标滚轮，`background` 模式的 PostMessage 方式无法实现精确的向上滚动。

### 网格坐标限制
本功能**不支持**绘制网格坐标。

**原因**：网格坐标用于定位元素，而滚动长截图用于查看内容，两者使用目的不同。

### 超时限制
单次请求有超时限制，超时时间 ≈ `max_scrolls × scroll_wait × 2 + 60` 秒。

## 常见问题

### Q1：为什么图片拼接有错位？

**可能原因**：
1. 页面滚动速度太快，还没加载完就截图了
2. 页面有动态内容（如加载动画、广告）

**解决方案**：
- 增大 `scroll_wait` 参数（如从 1.0 改为 1.5）

### Q2：为什么还没到底就停止了？

**可能原因**：`stop_threshold` 设置太大

**解决方案**：减小 `stop_threshold`（如从 0.0001 改为 0.00005）

### Q3：为什么到底了还继续滚动？

**可能原因**：`stop_threshold` 设置太小

**解决方案**：增大 `stop_threshold`（如从 0.0001 改为 0.0002）

### Q4：为什么有些内容被截断了？

**可能原因**：滚动太快，导致某些内容在两张截图之间被跳过

**解决方案**：
- 减小 `scroll_percent`（如从 0.85 改为 0.70）
- 增大 `target_overlap_max`（如从 0.45 改为 0.50）

## 工作流程

### 自适应阶段（前3张图）

```
截取第1屏 → 截取第2屏 → 检测重叠和固定区域
              ↓
         判断重叠比例
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
  太小      完美      太大
    ↓         ↓         ↓
 减小幅度    保持    增大幅度
    ↓         ↓         ↓
 回滚重试    接受    回滚重试
```

### 正常滚动阶段

```
使用确定的滚动幅度继续滚动
每次滚动后：
  1. 等待 scroll_wait 秒
  2. 截图
  3. 计算内容变化率
  4. 变化率 < 阈值 → 停止
  5. 继续下一轮
```

### 拼接阶段

```
1. 检测固定头部和底部
2. 裁剪所有截图
3. 逐对检测重叠量
4. 一致性约束（中位数或参考值）
5. 垂直拼接
6. 保存结果
```
