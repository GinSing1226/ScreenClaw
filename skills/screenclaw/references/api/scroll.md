# scroll - 滚动

## 使用目的
在指定位置执行鼠标滚轮滚动，用于：
- 浏览长内容（文章、网页）
- 滚动列表查看更多内容
- 上下滚动页面

## 什么时候用
- 需要浏览长内容或列表
- 需要上下滚动页面
- 内容超出可视范围

## 什么时候不用
- 触摸式滑动（使用swipe）
- 简单点击（使用click）

## 操作方式说明

### background（无感操作）
- **条件**：滚动坐标位置不能被其他软件遮挡
- **体验**：不抢夺鼠标，用户可以继续使用电脑
- **兼容性**：部分应用可能不响应

### hijack（劫持操作）
- **条件**：无特殊条件，但会短暂激活窗口
- **体验**：会短暂占用鼠标
- **确认**：执行前会弹出确认窗口，需用户确认

**建议**：优先尝试background，无效时使用hijack。

---

## delta参数说明

**delta值大小**：需要通过截图观察效果，不同应用可能差异很大
- 某些应用：`delta=1` 产生微小滚动
- 某些应用：需要 `delta=100` 甚至更大才能产生明显滚动
- **建议**：先试用小值（如 -120），根据效果调整

**滚动方向**：
- 负值（如 -120）：向下滚动
- 正值（如 120）：向上滚动

---

## 请求

**方法**：POST
**路径**：`/api/scroll`

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 | 从哪里获取 |
|------|------|------|--------|------|----------|
| `ai_app_type` | string | 是 | - | AI应用类型 | 判断当前AI是什么应用，就用什么值 |
| `session_id` | string | 是 | - | 会话唯一标识 | 获取当前会话唯一标识，获取不到则随机生成 |
| `window_id` | int | 是 | - | 目标窗口句柄 | 从get_window_list获取 |
| `main_window_id` | int | 建议 | - | 主窗口ID（用于激活最小化窗口） | 从get_window_list获取 |
| `x` | float | 是 | - | 鼠标位置横坐标（从截图的网格标记中直接读出的数字） | 从截图分析得出 |
| `y` | float | 是 | - | 鼠标位置纵坐标（从截图的网格标记中直接读出的数字） | 从截图分析得出 |
| `delta` | int | 是 | - | 滚动量（正值向上，负值向下） | 根据需要设置 |
| `action_method` | string | 否 | "background" | 操作方式：background/hijack | 优先background，坐标不能被遮挡 |

### 请求示例

#### 向下滚动一页（background模式，坐标不能被遮挡）
```json
{
  "ai_app_type": "claude_code",
  "session_id": "session-123",
  "window_id": 1001,
  "x": 50.0,
  "y": 50.0,
  "delta": -120,
  "action_method": "background"
}
```

#### 向下滚动一页（hijack模式，会弹出确认）
```json
{
  "ai_app_type": "claude_code",
  "session_id": "session-123",
  "window_id": 1001,
  "x": 50.0,
  "y": 50.0,
  "delta": -120,
  "action_method": "hijack"
}
```

## 响应

### 成功响应
```json
{
  "success": true,
  "message": "指令已发送，可截图验证结果"
}
```

## 错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| `WINDOW_NOT_FOUND` | 窗口不存在 | 重新获取窗口列表 |
| `USER_DENIED` | 用户拒绝操作 | 用户取消了确认弹窗 |

---

## 使用技巧

1. **delta值**：
   - `-120` = 向下滚动一页
   - `120` = 向上滚动一页
   - 可调整数值控制滚动距离

2. **鼠标位置**：x和y指定滚动时鼠标的位置，通常放在内容区域中央

3. **确认弹窗**：每次执行都会弹出确认窗口，需用户确认
