# wait - 等待

## 使用前必读

### 使用目的和效果
等待指定时长。用于UI动画完成、页面加载、异步响应等场景。不影响窗口状态，只是暂停执行。

### 适用场景
- 触发UI变化后等待（如点击后弹窗加载）
- 页面跳转后等待加载
- 操作之间添加延迟

### 不适用场景
- 不需要等待，可立即执行下一步

## 请求

**方法**：POST `/api/wait`

**请求头**：
```
Authorization: Bearer {token}
Content-Type: application/json
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `ai_app_type` | string | 是 | - | AI应用类型 |
| `session_id` | string | 是 | - | 会话唯一标识 |
| `window_id` | int | 是 | - | 目标窗口句柄 |
| `duration_ms` | int | 是 | - | 等待时长（毫秒） |

**注意**：`wait` 不需要 `main_window_id` 参数。

### 请求示例

```json
{
  "ai_app_type": "claude_code",
  "session_id": "session-123",
  "window_id": 1001,
  "duration_ms": 300
}
```

## 错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| `WINDOW_NOT_FOUND` | 窗口不存在 | 重新获取窗口列表 |

## 常见问题

### 遇到问题时的排查顺序
1. **等待后界面无变化** → 可能需要更长等待时间，或界面本就不会变化
2. **API调用失败** → 检查参数格式

### 操作技巧
- **常用等待时长**：200ms（简短延迟）、300ms（UI响应）、500ms（标准等待）、1000ms（页面加载）
- **操作后等待**：每次点击、输入等操作后建议添加wait等待UI稳定
- **批量操作**：在batch指令中使用wait，减少网络请求
