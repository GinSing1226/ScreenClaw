# wait - 等待

## 使用目的
等待指定时间，用于：
- 等待UI动画完成
- 等待页面加载
- 等待异步响应
- 操作之间添加延迟

## 什么时候用
- 触发UI变化的操作后需要等待（如点击按钮后弹窗加载）
- 页面跳转后需要等待加载
- 操作之间需要短暂延迟

## 什么时候不用
- 不需要等待，可立即执行下一步

---

## 请求

**方法**：POST
**路径**：`/api/wait`

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 | 从哪里获取 |
|------|------|------|--------|------|----------|
| `ai_app_type` | string | 是 | - | AI应用类型 | 判断当前AI是什么应用，就用什么值 |
| `session_id` | string | 是 | - | 会话唯一标识 | 获取当前会话唯一标识，获取不到则随机生成 |
| `window_id` | int | 是 | - | 目标窗口句柄 | 从get_window_list获取 |
| `duration_ms` | int | 是 | - | 等待时长（毫秒） | 根据需要设置 |

### 请求示例

#### 等待300毫秒
```json
{
  "ai_app_type": "claude_code",
  "session_id": "session-123",
  "window_id": 1001,
  "duration_ms": 300
}
```

#### 等待1秒
```json
{
  "ai_app_type": "claude_code",
  "session_id": "session-123",
  "window_id": 1001,
  "duration_ms": 1000
}
```

## 响应

### 成功响应
```json
{
  "success": true,
  "message": "等待完成"
}
```

## 使用技巧

1. **常用等待时长**：
   - `200ms` - 简短延迟
   - `300ms` - UI响应等待
   - `500ms` - 标准等待
   - `1000ms` - 页面加载等待

2. **操作后等待**：每次点击、输入等操作后，建议添加wait等待UI稳定

3. **批量操作**：在batch指令中使用wait，减少网络请求
