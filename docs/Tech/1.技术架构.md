## 技术栈

### Python 后端

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 运行时 | Python | 3.11 | 性能好，兼容性好 |
| Web框架 | FastAPI | >=0.100.0 | 异步、自动文档 |
| ASGI服务器 | Uvicorn | >=0.23.0 | 高性能 |
| 数据校验 | Pydantic | >=2.0.0 | 类型安全 |
| 图片处理 | Pillow | >=10.0.0 | 网格绘制、压缩 |
| Win32 API | pywin32 | >=305 | 截图、操作注入 |
| WinRT API | winsdk | >=1.0.0b10 | Graphics Capture |
| 操作模拟 | pyautogui | >=0.9.54 | SendInput兜底 |
| 打包工具 | PyInstaller | >=6.0.0 | 打包exe |

### Tauri 前端

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | Tauri 2.0 | Rust + Web |
| 前端 | HTML/CSS/JS | 监控面板UI |
| 子进程 | tauri-plugin-shell | 启动Python服务 |
| 多语言 | i18next | 前端UI国际化 |

### 多语言方案

**前端多语言**：
```
src/
├── locales/
│   ├── zh_CN.json    # 简体中文
│   ├── en_US.json    # English
│   └── ja_JP.json    # 日本語
└── i18n.js           # i18next配置
```

**后端错误码机制**：
```json
// 后端返回
{
  "success": false,
  "error_code": "PROCESS_NOT_FOUND",
  "message": "进程不存在"
}

// 前端根据 error_code 显示对应语言
```

**错误码清单**：

| 错误码 | 中文 | English |
|--------|------|---------|
| PROCESS_NOT_FOUND | 进程不存在 | Process not found |
| PROCESS_BLOCKED | 进程在禁止清单中 | Process is blocked |
| SCREENSHOT_FAILED | 截图失败 | Screenshot failed |
| OPERATION_FAILED | 操作失败 | Operation failed |
| USER_DENIED | 用户拒绝操作 | User denied |
| TIMEOUT | 操作超时 | Operation timeout |
| AUTH_FAILED | 认证失败 | Authentication failed |

## 调用链路

### 截图流程

```
API: /api/screenshot
    │
    ▼
api/screenshot.py (参数校验)
    │
    ▼
services/process_service.py (验证进程存在)
    │
    ▼
core/capture.py (编排截图逻辑)
    │
    ▼
platform/windows/capture.py (实际截图)
    │   ├─ PrintWindow (优先)
    │   └─ WinRT Graphics Capture (兜底)
    │
    ▼
core/grid.py (绘制网格)
    │
    ▼
utils/image.py (压缩图片)
    │
    ▼
services/log_service.py (记录日志)
    │
    ▼
返回响应
```

### 操作注入流程

```
API: /api/click
    │
    ▼
api/action.py (参数校验)
    │
    ▼
services/process_service.py (验证进程存在)
    │
    ▼
core/injector.py (编排注入逻辑)
    │
    ▼
platform/windows/input.py (实际注入)
    │   ├─ PostMessage (优先)
    │   └─ SendInput (兜底，需Tauri弹窗确认)
    │
    ▼
services/log_service.py (记录日志)
    │
    ▼
返回响应
```

## 配置管理

使用 Pydantic 管理配置：

```python
# models/config.py
from pydantic import BaseModel

class ServerConfig(BaseModel):
    port: int = 12261
    host: str = "0.0.0.0"
    token: str = ""
    local_ip: str = ""
    auto_start: bool = True
    service_enabled: bool = True

class AppConfig(BaseModel):
    server: ServerConfig
    # ... 其他配置
```
