## 打包目标

将 ScreenClaw 打包成用户可直接运行的应用：

```
screenClaw/
├── screenClaw.exe          # Tauri主程序
├── python-service.exe      # Python后端服务
├── config.json             # 配置文件（首次运行生成）
├── logs/                   # 日志目录（自动创建）
└── data/                   # 图片目录（自动创建）
```

## Python 打包

### 工具

使用 **PyInstaller** 打包。

### requirements.txt

```txt
# Web框架

# 操作模拟

# 打包
pyinstaller>=6.0.0
```

### 打包命令

```bash
pyinstaller --onefile --windowed \
  --name python-service \
  --hidden-import=winsdk \
  --hidden-import=winsdk.windows.foundation \
  --hidden-import=winsdk.windows.graphics.capture \
  --hidden-import=winsdk.windows.graphics.directx \
  --hidden-import=winsdk.windows.graphics.directx.direct3d11 \
  --hidden-import=uvicorn.logging \
  --hidden-import=uvicorn.loops \
  --hidden-import=uvicorn.loops.auto \
  --hidden-import=uvicorn.protocols \
  --hidden-import=uvicorn.protocols.http \
  --hidden-import=uvicorn.protocols.http.auto \
  --hidden-import=uvicorn.protocols.websockets \
  --hidden-import=uvicorn.protocols.websockets.auto \
  --hidden-import=uvicorn.lifespan \
  --hidden-import=uvicorn.lifespan.on \
  main.py
```


## 用户安装

### Windows 安装包

Tauri 打包后生成：
- `screenClaw_1.0.0_x64-setup.exe` - 安装程序
- `screenClaw_1.0.0_x64.msi` - MSI安装包

### 安装后目录

```
C:\Program Files\ScreenClaw\
├── screenClaw.exe
├── python-service.exe
├── config.json
├── resources/
│   └── ...
```

### 首次运行

1. 用户启动 `screenClaw.exe`
2. 自动检测并生成 `config.json`
3. 自动检测局域网IP
4. 生成随机Token
5. 启动 `python-service.exe`
6. 显示监控面板

## 配置文件处理

### 首次运行逻辑

```python
# services/config_service.py

import os
import json
from pathlib import Path

class ConfigService:
    DEFAULT_CONFIG = {
        "server": {
            "port": 12261,
            "host": "0.0.0.0",
            "token": "",  # 首次运行时生成
            "local_ip": "",  # 首次运行时检测
            "auto_start": True,
            "service_enabled": True
        },
        # ... 其他默认配置
    }

    def __init__(self, config_path: str = "config.json"):
        self.config_path = config_path
        self.config = self._load_or_create()

    def _load_or_create(self) -> dict:
        if os.path.exists(self.config_path):
            with open(self.config_path, 'r', encoding='utf-8') as f:
                return json.load(f)
        else:
            # 创建默认配置
            config = self.DEFAULT_CONFIG.copy()
            config["server"]["token"] = self._generate_token()
            config["server"]["local_ip"] = self._get_local_ip()
            self._save(config)
            return config

    def _generate_token(self) -> str:
        import secrets
        return secrets.token_hex(16)

    def _get_local_ip(self) -> str:
        import socket
        try:
            s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
            s.connect(("8.8.8.8", 80))
            ip = s.getsockname()[0]
            s.close()
            return ip
        except:
            return "127.0.0.1"

    def _save(self, config: dict):
        with open(self.config_path, 'w', encoding='utf-8') as f:
            json.dump(config, f, indent=2, ensure_ascii=False)
```
