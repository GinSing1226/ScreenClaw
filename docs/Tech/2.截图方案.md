## 方案1：PrintWindow

### 原理

请求窗口将自己的内容绘制到指定的设备上下文（DC）。

### 代码示例

```python
import win32gui
import win32ui
import win32con

def capture_by_printwindow(hwnd: int) -> bytes:
    """使用PrintWindow截图"""

    # 获取窗口尺寸
    rect = win32gui.GetWindowRect(hwnd)
    width = rect[2] - rect[0]
    height = rect[3] - rect[1]

    # 创建DC
    hwnd_dc = win32gui.GetWindowDC(hwnd)
    mfc_dc = win32ui.CreateDCFromHandle(hwnd_dc)
    save_dc = mfc_dc.CreateCompatibleDC()

    # 创建位图
    save_bitmap = win32ui.CreateBitmap()
    save_bitmap.CreateCompatibleBitmap(mfc_dc, width, height)
    save_dc.SelectObject(save_bitmap)

    # PrintWindow
    result = win32gui.PrintWindow(hwnd, save_dc.GetSafeHdc(), 0)

    if not result:
        raise Exception("PrintWindow failed")

    # 转换为Pillow Image
    # ... (后续处理)

    # 清理
    win32gui.DeleteObject(save_bitmap.GetHandle())
    save_dc.DeleteDC()
    mfc_dc.DeleteDC()
    win32gui.ReleaseDC(hwnd, hwnd_dc)

    return image
```

### 失败情况

- 窗口最小化
- 部分游戏/硬件加速窗口
- 窗口正在调整大小

### 黑屏检测

```python
def is_black_image(image) -> bool:
    """检测图片是否为黑屏"""
    import numpy as np
    arr = np.array(image)
    return arr.mean() < 5  # 平均像素值过低
```

## 封装实现

### platform/windows/capture.py

```python
from abc import ABC, abstractmethod
from typing import Optional
from PIL import Image

class CaptureResult:
    success: bool
    image: Optional[Image.Image]
    error: Optional[str]
    method: str  # "printwindow" | "winrt"

class WindowsCapture:

    def capture(self, hwnd: int) -> CaptureResult:
        """截图主入口"""

        # 方案1: PrintWindow
        result = self._capture_by_printwindow(hwnd)
        if result.success and not self._is_black(result.image):
            result.method = "printwindow"
            return result

        # 方案2: WinRT
        result = self._capture_by_winrt(hwnd)
        if result.success:
            result.method = "winrt"
            return result

        return CaptureResult(
            success=False,
            image=None,
            error="截图失败：所有方案均不可用",
```
