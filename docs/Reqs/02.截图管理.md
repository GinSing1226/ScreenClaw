## 需求描述

### 功能概述

对指定进程进行后台截图，在图片上绘制坐标网格，保存到本地并返回给AI应用。

#### 场景描述 (5W2H)

| 维度 | 描述 |
|------|------|
| **Who** | AI应用调用 |
| **What** | 截图 + 绘制网格 + 返回图片 |
| **Where** | 后台执行，不抢夺焦点 |
| **When** | AI需要识别软件界面时 |
| **Why** | 让AI通过视觉坐标定位操作位置 |
| **How** | 系统API截图 + Pillow绘制网格 |
| **How Much** | 支持任意分辨率，自动压缩 |

### 功能点说明

#### 截图

**使用时机**：AI需要识别软件界面元素位置时

**功能描述**：对指定进程进行后台截图，即使窗口被遮挡也能成功截图。

| 维度 | 描述 |
|------|------|
| **Trigger** | 收到 `/api/screenshot` 请求 |
| **Input** | 进程ID、网格参数 |
| **Process** | 调用系统API截图 → 绘制网格 → 压缩图片 → 保存 |
| **Output** | 图片路径、base64编码 |
| **Exception** | 进程不存在 → 返回失败 |

#### 网格绘制

**使用时机**：截图后自动绘制（可选择不绘制）

**功能描述**：在截图上绘制百分比坐标网格，帮助AI定位元素。

| 维度 | 描述 |
|------|------|
| **Trigger** | `coordinate_type` 不为 `no` |
| **Input** | 网格参数、坐标参数 |
| **Process** | 计算网格位置 → 绘制网格线 → 绘制坐标数字 |
| **Output** | 带网格的图片 |
| **Exception** | 无 |

**坐标规范**：
- 范围：0-100（百分比）
- 显示：默认整数（5, 10, 15...），可配置小数位
- 示例：坐标 `55, 65` 表示 55%宽度、65%高度的位置

#### 图片保存

**使用时机**：截图完成后自动保存

**功能描述**：将截图保存到本地指定目录。

| 维度 | 描述 |
|------|------|
| **Trigger** | 截图完成 |
| **Input** | 图片数据、AI应用类型、会话ID |
| **Process** | 生成文件名 → 保存到对应目录 |
| **Output** | 图片绝对路径 |
| **Exception** | 磁盘空间不足 → 返回失败 |

## 技术描述

### 数据模型

#### ScreenshotRequest

```
- ai_app_type: string       # AI应用类型
- session_id: string        # 会话ID
- process_id: int           # 进程ID
- coordinate_type: string   # 坐标类型：no / grid
- grid: object              # 网格参数（可选）
  - density: float          # 网格密度（0-100），默认5.0
  - opacity: int            # 网格透明度（0-100），默认50
  - color: string           # 网格颜色（HEX），默认#00FF00
- coordinate: object        # 坐标参数（可选）
  - number_density: int     # 数字密度，默认2
  - number_decimal: int     # 小数位，默认0
  - number_size: int        # 字体大小（px），默认8
  - number_color: string    # 数字颜色（HEX），默认#00FF00
  - number_opacity: int     # 数字透明度（0-100），默认100
```

#### ScreenshotResponse

```
- success: bool
- message: string
- data: object
  - image_path: string      # 图片本地绝对路径
  - image_base64: string    # 图片base64编码
```

### 边界情况

| 场景 | 处理方式 |
|------|----------|
| 进程不存在 | 返回失败：进程不存在 |
| 窗口最小化 | 尝试截图，可能返回黑屏 |
| 大分辨率截图 | 自动压缩，限制最大宽度1920px |
| 磁盘空间不足 | 返回失败：磁盘空间不足 |
