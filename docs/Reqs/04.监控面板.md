## 需求描述

### 功能概述

Tauri桌面应用面板，用于查看日志、控制服务、配置系统设置。

#### 场景描述 (5W2H)

| 维度 | 描述 |
|------|------|
| **Who** | 普通用户 |
| **What** | 桌面面板，查看日志、控制服务、修改配置 |
| **Where** | Windows/macOS/Linux 桌面 |
| **When** | 用户需要查看AI操作记录或修改设置时 |
| **Why** | 提供可视化的管理和监控界面 |
| **How** | Tauri应用，读取配置和日志文件 |
| **How Much** | 轻量级，启动快 |

### 功能点说明

#### 服务控制

**使用时机**：用户需要启动或停止Python服务时

**功能描述**：控制Python服务的启动和停止。

| 维度 | 描述 |
|------|------|
| **Trigger** | 用户点击"启动/停止服务"按钮 |
| **Input** | 用户操作 |
| **Process** | 切换服务状态 → 更新配置 → 启动/停止Python子进程 |
| **Output** | 服务状态变更 |
| **Exception** | Python进程启动失败 → 显示错误信息 |

#### 日志查看

**使用时机**：用户需要查看AI操作历史时

**功能描述**：查看指令执行历史日志，支持筛选和搜索。

| 维度 | 描述 |
|------|------|
| **Trigger** | 用户打开监控面板 |
| **Input** | 筛选条件（AI应用、会话、日期）、搜索关键词 |
| **Process** | 读取日志文件 → 过滤 → 显示 |
| **Output** | 日志列表 |
| **Exception** | 日志文件不存在 → 显示空列表 |

#### 日志详情

**使用时机**：用户点击某条日志时

**功能描述**：查看单条日志的完整详情（params、result）。

| 维度 | 描述 |
|------|------|
| **Trigger** | 用户点击日志条目 |
| **Input** | 日志ID |
| **Process** | 弹窗展示完整JSON |
| **Output** | 日志详情弹窗 |
| **Exception** | 无 |

## 窗口行为

| 行为 | 说明 |
|------|------|
| 关闭窗口 | 最小化到系统托盘，服务继续运行 |
| 托盘图标 | 右键菜单：显示窗口 / 启动停止服务 / 退出 |
| 退出程序 | 停止Python服务，完全退出 |
| 开机自启 | 可配置，注册系统启动项 |

## 技术描述

### Tauri职责

| 职责 | 说明 |
|------|------|
| 启动Python服务 | 拉起子进程，监听HTTP |
| 显示服务状态 | 运行中/已停止，访问地址 |
| 监控面板 | 读取日志文件，展示列表 |
| 系统设置 | 读写配置文件 |
| 托盘图标 | 后台运行，快捷操作 |

### 边界情况

| 场景 | 处理方式 |
|------|----------|
| Python进程崩溃 | 自动重启，显示警告 |
| 配置文件损坏 | 恢复默认配置 |
| 日志文件过大 | 分页加载，避免卡顿 |
