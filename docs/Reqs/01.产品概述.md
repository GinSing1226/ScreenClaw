## 需求描述

### 功能概述

#### 场景描述 (5W2H)

| 维度 | 描述 |
|------|------|
| **Who** | 普通小白用户（非技术人员），使用Windows/macOS/Linux |
| **What** | 一个"中间件"程序：截图+网格 → HTTP接口 → 接收指令执行操作 |
| **Where** | 本地运行，局域网访问，开箱即用 |
| **When** | AI应用需要操作无API的软件时 |
| **Why** | AI应用无法操作无API的软件，需要提供视觉坐标+操作注入能力 |
| **How** | Tauri前端 + Python后端，HTTP通信 |
| **How Much** | MVP阶段，功能最小化 |

#### 期望效果

本程序**不包含任何 AI 模型和复杂推理逻辑**。它的唯一职责是：

1. 在**后台无感**地截取软件画面，叠加视觉坐标系（网格/标记），存放到本地供AI应用读取
2. 接收外部AI应用输出的指令，将坐标解析为底层的系统句柄指令（或ADB指令），向软件**注入后台点击/滑动等操作**
3. 全程不抢夺用户真实的物理键鼠，允许用户在看电影、写文档的同时，AI应用在后台中完成自动化任务

### 产品定位

AI应用的可视化操作必备伴侣。让AI应用操作任何屏幕。

## 技术描述

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | Tauri | 监控面板、系统设置、启动Python服务 |
| 后端 | Python + FastAPI | HTTP服务，处理所有核心逻辑 |
| 通信 | HTTP | 局域网访问，端口12261 |
| 截图 | pywin32 / mss | 后台截图，支持被遮挡窗口 |
| 操作注入 | pywin32 / ADB | 后台点击、滑动、输入 |
| 网格绘制 | Pillow (PIL) | 在截图上绘制坐标网格 |

### 架构设计

```
┌─────────────────────────────────────────────┐
│              Tauri 前端                      │
│  (监控面板 / 系统设置 / 启动停止服务)         │
└──────────────┬──────────────────────────────┘
               │ 子进程管理
┌──────────────▼──────────────────────────────┐
│           Python 后端服务                     │
│         FastAPI (localhost:12261)           │
├─────────────────────────────────────────────┤
│  api/        │ core/       │ platform/      │
│  路由层      │ 业务逻辑    │ 平台适配        │
└─────────────────────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│           外部 AI 应用                       │
│  (Claude Code / OpenClaw / 其他Agent)        │
└─────────────────────────────────────────────┘
```
