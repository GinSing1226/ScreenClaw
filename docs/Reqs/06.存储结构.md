## 需求描述

### 功能概述

定义ScreenClaw的文件存储结构，包括日志、图片、配置文件的组织方式。

## 目录结构

```
screenClaw/
├── config.json                           # 配置文件
│
├── logs/                                 # 日志目录
│   └── {ai_app_type}-{session_id}-{yyyy-mm-dd}.jsonl
│
├── data/                                 # 图片存储目录
│   └── {ai_app_type}-{session_id}-{yyyy-mm-dd}/
│       └── screenshot-{hhmmss}-{rand4}.png
│
└── screenClaw.exe                        # 主程序（Tauri打包）
```

## 日志文件

### 文件命名

```
{ai_app_type}-{session_id}-{yyyy-mm-dd}.jsonl
```

**示例**：
```
claude_code-abc123-2026-03-25.jsonl
openclaw-session001-2026-03-25.jsonl
```

### 文件格式

JSONL格式（每行一个JSON对象）。

### 日志结构

```json
{
  "timestamp": "2026-03-25T14:32:15.123Z",
  "process_id": 12345,
  "process_name": "MuMuPlayer.exe",
  "instruction": "screenshot",
  "params": {
    "coordinate_type": "grid",
    "grid_density": 5.0
  },
  "result": {
    "success": true,
    "message": "截图成功",
    "data": {
      "image_path": "D:/screenClaw/data/claude_code-abc123-2026-03-25/screenshot-143215-a7f2.png"
    }
  },
  "duration_ms": 156
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `timestamp` | string | ISO8601格式时间戳 |
| `process_id` | int | 目标进程ID |
| `process_name` | string | 目标进程名称 |
| `instruction` | string | 指令类型 |
| `params` | object | 请求参数 |
| `result` | object | 执行结果 |
| `duration_ms` | int | 执行耗时（毫秒） |

### 图片日志

日志中只记录图片路径，不记录base64（避免日志文件过大）。

## 图片文件

### 文件夹命名

```
{ai_app_type}-{session_id}-{yyyy-mm-dd}/
```

**示例**：
```
claude_code-abc123-2026-03-25/
openclaw-session001-2026-03-25/
```

### 文件命名

```
screenshot-{hhmmss}-{rand4}.png
```

| 部分 | 说明 | 示例 |
|------|------|------|
| `hhmmss` | 时分秒 | 143215 |
| `rand4` | 4位随机字符 | a7f2 |

**示例**：
```
screenshot-143215-a7f2.png
screenshot-143220-b3c4.png
screenshot-143315-d5e6.png
```

### 图片格式

- 默认格式：PNG
- 自动压缩：超过1920px宽度时自动缩放
- 压缩质量：可配置（默认85）

## 清理策略

| 类型 | 策略 |
|------|------|
| 日志 | 超过 `retention_days` 天自动删除 |
| 图片 | 与日志同步清理（删除对应日期文件夹） |
| 配置 | 永久保留 |

---

## 边界情况

| 场景 | 处理方式 |
|------|----------|
| 目录不存在 | 自动创建 |
| 文件名冲突 | 重新生成随机字符 |
| 磁盘空间不足 | 返回错误，记录日志 |
| 会话跨天 | 按日期拆分日志文件 |
