## 需求描述

### 功能概述

外部AI应用通过HTTP接口控制ScreenClaw执行操作。

#### 通用规范

**请求头**：
```
Authorization: Bearer {token}
Content-Type: application/json
```

**通用请求字段**（每个API都需要）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ai_app_type` | string | ✅ | AI应用类型（如 `claude_code`） |
| `session_id` | string | ✅ | 会话唯一标识 |

**通用响应结构**：
```json
{
  "success": true,
  "message": "执行成功",
  "data": { /* 具体数据 */ }
}
```

## API详情

### 健康检查

**GET `/api/health`**

用于AI应用检测服务是否启动。

**响应**：
```json
{
  "success": true,
  "message": "服务正常",
  "data": {
    "version": "1.0.0",
    "uptime_seconds": 3600
  }
}
```

---

### 获取进程列表

**POST `/api/get_process_list`**

获取当前系统所有可见窗口进程。

**请求**：
```json
{
  "ai_app_type": "claude_code",
  "session_id": "abc123",
  "keyword": "mumu"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyword` | string | ❌ | 模糊搜索窗口名，不分大小写。为空返回所有进程 |

**响应**：
```json
{
  "success": true,
  "message": "获取成功",
  "data": {
    "processes": [
      {
        "process_id": 12345,
        "process_name": "MuMuPlayer.exe",
        "window_title": "MuMu模拟器12"
      }
    ]
  }
}
```

### 截图

**POST `/api/screenshot`**

对指定进程截图，可选绘制坐标网格。

**请求**：
```json
{
  "ai_app_type": "claude_code",
  "session_id": "abc123",
  "process_id": 12345,
  "coordinate_type": "grid",
  "grid": {
    "density": 5.0,
    "opacity": 50,
    "color": "#00FF00"
  },
  "coordinate": {
    "number_density": 2,
    "number_decimal": 0,
    "number_size": 8,
    "number_color": "#00FF00",
    "number_opacity": 100
  }
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `process_id` | int | ✅ | - | 目标进程ID |
| `coordinate_type` | string | ❌ | `grid` | 坐标类型：`no` / `grid` |
| `grid.density` | float | ❌ | 5.0 | 网格密度（0-100） |
| `grid.opacity` | int | ❌ | 50 | 网格透明度（0-100） |
| `grid.color` | string | ❌ | #00FF00 | 网格颜色（HEX） |
| `coordinate.number_density` | int | ❌ | 2 | 数字显示密度 |
| `coordinate.number_decimal` | int | ❌ | 0 | 坐标小数位 |
| `coordinate.number_size` | int | ❌ | 8 | 字体大小（px） |
| `coordinate.number_color` | string | ❌ | #00FF00 | 数字颜色（HEX） |
| `coordinate.number_opacity` | int | ❌ | 100 | 数字透明度（0-100） |

**响应**：
```json
{
  "success": true,
  "message": "截图成功",
  "data": {
    "image_path": "D:/screenClaw/data/claude_code-abc123-2026-03-25/screenshot-143215-a7f2.png",
    "image_base64": "iVBORw0KGgoAAAANSUhEUgAA..."
  }
}
```

### 滑动

**POST `/api/swipe`**

从起始坐标滑动到终止坐标。

**请求**：
```json
{
  "ai_app_type": "claude_code",
  "session_id": "abc123",
  "process_id": 12345,
  "target_type": "mobile",
  "start_x": 50.0,
  "start_y": 80.0,
  "end_x": 50.0,
  "end_y": 20.0
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `target_type` | string | ❌ | `pc` | 目标类型：`pc` / `mobile` |
| `start_x` | float | ✅ | - | 起始横坐标（0-100） |
| `start_y` | float | ✅ | - | 起始纵坐标（0-100） |
| `end_x` | float | ✅ | - | 结束横坐标（0-100） |
| `end_y` | float | ✅ | - | 结束纵坐标（0-100） |

**target_type 说明**：
- `pc`：PC原生软件，使用鼠标拖拽
- `mobile`：模拟器里的手机APP，使用ADB指令

**响应**：
```json
{
  "success": true,
  "message": "滑动成功"
}
```

### 输入文本

**POST `/api/input_text`**

点击指定坐标位置，然后输入文本。支持 `\n` 换行。

**请求**：
```json
{
  "ai_app_type": "claude_code",
  "session_id": "abc123",
  "process_id": 12345,
  "target_type": "pc",
  "x": 55.0,
  "y": 65.0,
  "text": "第一行\n第二行"
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `target_type` | string | ❌ | `pc` | 目标类型 |
| `x` | float | ✅ | - | 输入位置横坐标（0-100） |
| `y` | float | ✅ | - | 输入位置纵坐标（0-100） |
| `text` | string | ✅ | - | 输入文本，`\n` 表示换行 |

**换行处理**：
| target_type | 换行映射 |
|-------------|----------|
| `pc` | Shift+Enter |
| `mobile` | Enter（ADB keyevent 66） |

**响应**：
```json
{
  "success": true,
  "message": "输入成功"
}
```

### 组合指令

**POST `/api/batch`**

批量执行多条指令，按顺序执行。某条失败时立即中断。

**请求**：
```json
{
  "ai_app_type": "claude_code",
  "session_id": "abc123",
  "process_id": 12345,
  "instructions": [
    { "action": "click", "params": { "x": 50.0, "y": 30.0 } },
    { "action": "wait", "params": { "duration_ms": 500 } },
    { "action": "input_text", "params": { "x": 50.0, "y": 60.0, "text": "hello" } }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `instructions` | array | ✅ | 指令数组 |
| `instructions[].action` | string | ✅ | 指令类型 |
| `instructions[].params` | object | ✅ | 指令参数（不需要传ai_app_type/session_id/process_id） |

**响应（成功）**：
```json
{
  "success": true,
  "message": "执行完成",
  "data": {
    "executed_count": 3,
    "results": [
      { "success": true, "message": "点击成功" },
      { "success": true, "message": "等待完成" },
      { "success": true, "message": "输入成功" }
    ]
  }
}
```

**响应（失败中断）**：
```json
{
  "success": false,
  "message": "执行中断：第2条指令失败",
  "data": {
    "executed_count": 1,
    "failed_index": 1,
    "results": [
      { "success": true, "message": "点击成功" },
      { "success": false, "message": "等待失败：进程已关闭" }
    ]
  }
}
```
