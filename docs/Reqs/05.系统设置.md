## 功能清单

| 功能 | 状态 | 说明 |
|------|------|------|
| Token配置 | 🚧 | 设置/重新生成API访问令牌 |
| 端口配置 | 🚧 | 设置HTTP服务端口，默认12261 |
| 截图默认值 | 🚧 | 网格密度、颜色、透明度、字体等默认参数 |
| 图片压缩配置 | 🚧 | 图片质量、最大宽度限制 |
| 换行映射配置 | 🚧 | PC/Mobile端换行键位映射 |
| 禁止访问清单 | 🚧 | 设置禁止操作的进程名列表 |
| 日志保留天数 | 🚧 | 设置日志自动清理天数 |
| 语言切换 | 🚧 | 切换界面语言：中文/英文/日文 |
| 开机自启动 | 🚧 | 设置是否开机自动启动服务 |

## 需求描述

### 功能概述

用户可配置的各项系统参数，保存在 `config.json` 文件中。

### 配置分类

| 分类 | 说明 |
|------|------|
| 服务配置 | 端口、Token、服务状态 |
| 截图默认值 | 网格、坐标、图片质量 |
| 输入配置 | 换行映射 |
| 安全设置 | 禁止访问清单 |
| 日志配置 | 保留天数 |
| 界面配置 | 语言、开机自启 |

## 技术描述

### 配置文件结构

**文件路径**：`config.json`

```json
{
  "server": {
    "port": 12261,
    "host": "0.0.0.0",
    "token": "your-secret-token-here",
    "local_ip": "192.168.10.128",
    "auto_start": true,
    "service_enabled": true
  },
  "screenshot": {
    "default_coordinate_type": "grid",
    "default_grid_density": 5.0,
    "default_grid_opacity": 50,
    "default_grid_color": "#00FF00",
    "default_number_density": 2,
    "default_number_decimal": 0,
    "default_number_size": 8,
    "default_number_color": "#00FF00",
    "default_number_opacity": 100,
    "image_quality": 85,
    "max_image_width": 1920
  },
  "input": {
    "newline_mapping": {
      "pc": "shift+enter",
      "mobile": "enter"
    }
  },
  "security": {
    "blocked_processes": []
  },
  "log": {
    "retention_days": 30
  },
  "ui": {
    "language": "zh_CN"
  }
}
```

### 字段说明

#### server 服务配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `port` | int | 12261 | HTTP服务端口 |
| `host` | string | 0.0.0.0 | 绑定地址 |
| `token` | string | - | API访问令牌 |
| `local_ip` | string | - | 局域网IP（自动检测） |
| `auto_start` | bool | true | 开机自启动 |
| `service_enabled` | bool | true | 服务是否启用 |

#### screenshot 截图配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `default_coordinate_type` | string | grid | 默认坐标类型 |
| `default_grid_density` | float | 5.0 | 默认网格密度 |
| `default_grid_opacity` | int | 50 | 默认网格透明度 |
| `default_grid_color` | string | #00FF00 | 默认网格颜色 |
| `default_number_density` | int | 2 | 默认数字密度 |
| `default_number_decimal` | int | 0 | 默认小数位 |
| `default_number_size` | int | 8 | 默认字体大小 |
| `default_number_color` | string | #00FF00 | 默认数字颜色 |
| `default_number_opacity` | int | 100 | 默认数字透明度 |
| `image_quality` | int | 85 | 图片压缩质量（1-100） |
| `max_image_width` | int | 1920 | 最大图片宽度，超过自动缩放 |

#### input 输入配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `newline_mapping.pc` | string | shift+enter | PC端换行映射 |
| `newline_mapping.mobile` | string | enter | 手机端换行映射 |

#### security 安全配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `blocked_processes` | array | [] | 禁止访问的进程名列表 |

#### log 日志配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `retention_days` | int | 30 | 日志保留天数 |

#### ui 界面配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `language` | string | zh_CN | 界面语言：zh_CN / en_US / ja_JP |

---

### 语言支持

| 语言代码 | 语言名称 |
|----------|----------|
| `zh_CN` | 简体中文 |
| `en_US` | English |
| `ja_JP` | 日本語 |

---

### 边界情况

| 场景 | 处理方式 |
|------|----------|
| 配置文件不存在 | 自动创建默认配置 |
| 配置文件损坏 | 恢复默认配置，备份损坏文件 |
| 端口被占用 | 自动递增端口，更新配置 |
| Token为空 | 生成随机Token |
