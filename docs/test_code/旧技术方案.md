## 二、核心模块实现

### 2.1 窗体管理器 (WindowManager)

**文件**: `src/core/window_manager.py`

**功能**:
- 枚举系统所有可见窗口
- 识别模拟器进程（MuMu、雷电、夜神等）
- 遍历子窗口，定位渲染子句柄（Render HWND）

**关键技术**:

| API | 用途 |
|-----|------|
| `win32gui.EnumWindows` | 枚举顶层窗口 |
| `win32gui.EnumChildWindows` | 枚举子窗口 |
| `win32gui.GetClassName` | 获取窗口类名 |
| `win32process.GetWindowThreadProcessId` | 获取进程 ID |

**MuMu 12 窗口结构**:
```
MuMu 主窗口 (外壳)
└── 渲染子窗口 (Qt5QWindowIcon / MuMuPlayer)  ← 真正的游戏画面
```

**代码示例**:
```python
from core.window_manager import WindowManager

mgr = WindowManager()
# 查找 MuMu 模拟器窗口
windows = mgr.find_emulator_windows('mumu')

# 获取渲染子窗口
render = mgr.find_render_window(windows[0].hwnd)
```

### 2.2 截图引擎 (ScreenCapture)

**文件**: `src/core/capture.py`

**支持的截图方式**:

| 方式 | 后台截图 | 性能 | 兼容性 |
|------|---------|------|--------|
| PrintWindow | ✅ 支持 | 中等 | Windows XP+ |
| BitBlt | ❌ 需前台 | 高 | 所有版本 |

**PrintWindow 实现** (核心代码):

```python
import ctypes
from ctypes import windll, c_void_p, byref

# 创建 DIB 位图
bmi = ctypes.create_string_buffer(40)
# ... 设置 BITMAPINFOHEADER ...

pbits = c_void_p()
hbitmap = windll.gdi32.CreateDIBSection(hwnd_dc, bmi, 0, byref(pbits), None, 0)

# 调用 PrintWindow
windll.user32.PrintWindow(hwnd, mem_dc, flags)

# 读取像素数据
pixel_buffer = ctypes.create_string_buffer(width * height * 4)
ctypes.memmove(pixel_buffer, pbits, buffer_size)
```

**PrintWindow Flags**:
- `0x1` (PW_CLIENTONLY): 仅客户区
- `0x2` (PW_RENDERFULLCONTENT): 完整渲染内容（Windows 8.1+）

**网格叠加** (GridOverlay):

```python
from core.capture import GridOverlay, GridConfig

config = GridConfig(
    interval=0.1,        # 10% 间隔
    line_color=(255, 0, 0, 128),
    text_color=(255, 255, 0, 200),

overlay = GridOverlay(config)
```

### 2.3 控制引擎 (WindowController)

**文件**: `src/core/controller.py`

**实现原理**: 通过 Win32 消息注入实现后台操作，不移动物理鼠标。

**核心消息**:

| 消息 | 用途 |
|------|------|
| `WM_LBUTTONDOWN` | 左键按下 |
| `WM_LBUTTONUP` | 左键释放 |
| `WM_MOUSEMOVE` | 鼠标移动 |
| `WM_MOUSEWHEEL` | 滚轮滚动 |

**坐标打包**:
```python
lparam = win32api.MAKELONG(x, y)  # 低16位=X, 高16位=Y
```

**点击实现**:
```python
import win32gui
import win32con
import win32api

def click(hwnd, x, y):
    lparam = win32api.MAKELONG(x, y)
    win32gui.PostMessage(hwnd, win32con.WM_LBUTTONDOWN, 0x0001, lparam)
    time.sleep(0.05)
    win32gui.PostMessage(hwnd, win32con.WM_LBUTTONUP, 0, lparam)
```

**滑动实现**:
```python
def swipe(hwnd, x1, y1, x2, y2, steps=10):
    lparam = win32api.MAKELONG(x1, y1)
    win32gui.PostMessage(hwnd, win32con.WM_LBUTTONDOWN, 0x0001, lparam)

    for i in range(1, steps + 1):
        progress = i / steps
        x = int(x1 + (x2 - x1) * progress)
        y = int(y1 + (y2 - y1) * progress)
        lparam = win32api.MAKELONG(x, y)
        win32gui.PostMessage(hwnd, win32con.WM_MOUSEMOVE, 0x0001, lparam)
        time.sleep(0.01)

    lparam = win32api.MAKELONG(x2, y2)
    win32gui.PostMessage(hwnd, win32con.WM_LBUTTONUP, 0, lparam)
```

**注意事项**:
- 部分游戏监听 Raw Input 而非 Win32 消息，此方式可能无效
- 如遇无效情况，备选方案：通过 ADB 发送指令

## 三、坐标系统

采用**百分比坐标**，范围 0.0 ~ 1.0：

```
(0,0) ─────────────── (1,0)
  │                      │
  │    (0.5, 0.5)        │
  │       中心点         │
  │                      │
(0,1) ─────────────── (1,1)
```

**转换公式**:
```python
pixel_x = int(percent_x * window_width)
pixel_y = int(percent_y * window_height)
```
